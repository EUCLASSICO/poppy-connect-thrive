# Poppy: Connect & Thrive

Crie um aplicativo mobile profissional chamado Poppy, uma plataforma moderna de trabalho e freelancing que conecta trabalhadores, freelancers e empresas.

O Poppy deve ter uma identidade visual moderna, premium, simples e confiável. Evite aparência infantil, excesso de elementos ou estética genérica de IA.

Identidade visual

Nome: Poppy

Estilo: moderno, profissional, tecnológico e amigável

Interface limpa e elegante

Cantos levemente arredondados

Tipografia moderna e altamente legível

Fundo claro com possibilidade de modo escuro

Paleta principal baseada em branco, preto, roxo e um pequeno destaque em rosa

Ícones simples e consistentes
